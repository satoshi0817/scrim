# Scrim

[English](README.en.md)

Scrimは、作業中の画面に予定・時計・Webページなどを重ねて表示するmacOSアプリです。メニューバーから開くか、⌘を2回押して呼び出せます。

## はじめに

1. Scrimを起動し、メニューバーのScrimから「レイアウトを編集…」を選びます。
2. 「パネルを追加」のカードをクリックするか、一覧から置きたい場所へドラッグします。新しいパネルは横2×縦1マスです。ドラッグ中に周囲のパネルが移動・縮小して置き場所が見えます。端をドラッグしてサイズを変え、離すとグリッドに揃います。「完了」で通常表示に戻ります。
3. ⌘を短く2回押すたびに固定表示が開閉し、2回目を押したままにすると一時表示になります。ジェスチャーにはmacOSの「入力監視」の許可が必要です。固定表示中は ⌘, で設定や編集を選び、⌘⇧E で編集を切り替えられます。Escや別のアプリへの切り替えで閉じます。

レイアウト編集中は画面下の「＋」で空のページを追加できます。固定表示中に2本指で横スクロールするか、⌥⌘←／⌥⌘→（設定 → 操作で修飾キーを変更可能）、または下部のドットで切り替えます。各ページの配置と最後に開いたページを記憶します。

レイアウト編集中にパネルへポインタを乗せると、そのパネルがぼけて（形はわかるが文字は読めない程度）、中央に「クリックでメニュー · ドラッグで移動」が表示されます。パネルをクリックする（右クリックでも可）と、ぼけたパネルの上にそのパネルの設定とメニューがふわっと表示されます。ドラッグすると移動します。パネルを取り除くには、この画面の「パネルを削除」を選びます。「完了」で元に戻ります。ページ全体を取り除くには、画面下の対象ページ番号をクリックし、「ページ N 全体を削除…」を選んで確定します。番号を別の番号へドラッグすると、ページを並べ替えられます。

### 複数のディスプレイ

Scrimは、呼び出したときにポインタがあるディスプレイに表示します。設定 → パネル →「ディスプレイ」で次の項目を変更できます。

- **すべてのディスプレイで同じ配置**：オン（初期値）では、どの画面でも同じパネルを、画面に対する比率を保って表示します。オフにすると、パネルの位置・サイズ・重なり順だけを画面ごとに記憶します。パネルの追加・削除やURLは、すべての画面で共通です。切り替えたときは直前の配置を引き継ぎます。オンに戻すと、最後にパネルを追加・削除・移動した画面の配置が共通になります。
- **表示するディスプレイ**：接続中のディスプレイごとにオン・オフを切り替えます。オフの画面にポインタがあるときは、ジェスチャーやショートカットで呼び出しても開きません。メニューバーの「開く」「レイアウトを編集…」「設定…」は、オンの画面に表示します。ノッチの予定タイマーは、この設定とは別に動きます。

## 追加できるパネル

| パネル | できること |
| --- | --- |
| 次の予定・月間カレンダー | 日ごとの予定、開始までの時間、出欠を確認できます。カレンダーの選択、表示日数、除外キーワードを設定でき、直近の会議には参加リンクが表示されます。予定の読み取りにはmacOSのカレンダーへのアクセスを許可してください。Google OAuthの設定は不要です。 |
| 時計・世界時計 | アナログとデジタルを切り替えられます。デジタル時計は複数都市の時刻、世界時計は勤務時間の重なりを表示します。 |
| 東京の天気・電卓 | 気温と任意の3時間ごとの予報を確認したり、キーボードで四則演算したりできます。 |
| Notionタスク | Notionのデータベースにある未完了のタスクを、期限の近い順に表示します。タスクの追加、完了（直後は取り消し可）、タスク名と期限の編集ができます。 |
| Web・Notion・ファイル | WebページやNotionデータベースのビュー、PDF、テキスト、画像やCSSを含むローカルHTMLを配置できます。 |

WebパネルのURLや表示幅を変更するには、レイアウト編集中にそのパネルをクリックし、「Webパネル設定…」を開きます。PC表示とスマホ表示はパネルごとに保存されます。

### Notionタスク

1. Notionの開発者ポータルで、個人アクセストークンか内部接続を作り、トークンをコピーします。個人アクセストークンには、作成時に選んだ有効期限（初期値は1年）があります。期限が切れたら、新しいトークンを登録し直してください。
2. Scrimの設定 → パネル →「Notion」にトークンを貼り付け、「保存して確認」を押します。トークンはこのMacのキーチェーンだけに保存されます。
3. 内部接続を使う場合は、Notionで使うデータベースの「•••」→「接続」から、その接続を追加します。新しくデータベースを作る場合は、作成先のページにも追加します。
4. レイアウト編集で「Notionタスク」を追加し、編集を終えて「データベースを設定…」を押します。既存のデータベースを検索して選ぶか、データベースのURL（「リンクをコピー」）やIDを貼り付けて「開く」を押すか、「新しく作成…」で作成先のページを選びます。
5. 既存のデータベースでは、完了に使う列（チェックボックスかステータス）と期限の列（日付、任意）を選びます。ステータスの場合は、完了にする値を選びます。同じグループ（例：Complete）の値は、すべて完了済みとして一覧から外れます。

タスクをクリックすると、パネルの中でそのタスクを開きます。名前・期限・ステータスの変更と、ページ本文の表示・編集ができます。本文の段落・見出し・箇条書き・番号付きリスト・ToDo・引用・コールアウト・コードは、クリックすると文字を直せます。ToDoはチェックを切り替えられます。下の欄から段落・ToDo・箇条書きを末尾に追加でき、削除は「削除」を2回押して確定します（Notionのゴミ箱に移ります）。太字やリンクなど書式を含むブロック、画像・表などは表示だけで、編集はNotionで行います（鍵のマークが付きます）。右上のボタンでNotionで開けます。

一覧の上の欄に入力すると、タスク名で絞り込めます。右の絞り込みボタンでは、期限（期限切れ・今日まで・今週まで・期限なし）、ステータスやタグ（セレクト・マルチセレクトの列）、担当者で絞り込めます。この3つの条件はパネルごとに保存されます。文字の絞り込みは保存されません。担当者で絞り込むには、「データベースと列を設定…」で担当者（ユーザー）の列を選んでください。

タスクの文字サイズは、設定 → パネル →「Notion」の「タスクの文字サイズ」で、小・標準・大・特大から選べます。表示中は1分ごとに更新します。設定はあとから、パネルのメニューの「データベースと列を設定…」で変更できます。

設定で外観、一時表示中のクリックやスクロール、画面ごとの配置を変更できます。「次の予定」を追加すると、対応するMacのノッチ横に承諾済みの予定のカウントダウンも表示できます。

「次の予定」では青いチェックが承諾済み、琥珀色の「？」が未回答です。開始30分前からカードの内側に色が付き、開始が近づくほど赤みが増します。スクロール中は細い半透明のバーがカードに重なります。

**設定 → パネル → ノッチの予定タイマー → 表示を試す** で、実際の予定がなくても開始前・進行中の表示を確認できます。残り時間のスライダーを動かすと、ノッチのアイコンと時間表示の色が変わります。

設定 → 一般で実行中のバージョンとGitHubの最新公開版を確認できます。更新通知と自動インストールは個別にオンにできます。自動確認は起動時と6時間ごとで、インストールした版は次の起動から使えます。

## メモリの使い方

Webパネルは、ページごとにWebKitのプロセスを使うため、メモリを最も多く使います。Scrimは次のようにして使用量を抑えます。

- Scrimを閉じたまま10分たつと、Webパネルのページを解放します。次に開いたときに読み込み直します。設定 → パネル →「メモリ」でオフにできます。ログインは保たれますが、入力途中の内容やスクロール位置は戻りません。
- ページを切り替えたときに保持するWebセッションは、直前のページの1つ分だけです。
- macOSのメモリが不足したときは、Scrimを閉じていれば、すぐにWebパネルのページを解放します。

## ソースからビルド

macOS 14以降と、macOS 26 SDKを含むXcodeまたはCommand Line Toolsを用意してください。アプリバンドルの作成にはキーチェーンのコード署名証明書も必要です。

```sh
git clone https://github.com/satoshi0817/scrim.git
cd scrim
./scripts/build-scrim.sh
open build/Scrim.app
```

スクリプトはApple Development証明書を自動選択します。別の署名証明書を指定する場合は `SIGNING_IDENTITY` を設定してください。常用するときはアプリを `/Applications` にコピーしてから権限を付与してください。パッケージのビルドは `swift build`、XCTestを含むXcode環境でのテストは `swift test` です。
