# Scrim 1.1.0

## 日本語

複数のディスプレイでの配置、Notionタスク、メモの編集を中心に、日常の作業で使いやすくしました。

### 新機能と改善

- **ディスプレイごとの配置**：パネルの内容は全画面で共有し、位置・サイズ・重なり順と表示のオン／オフを画面ごとに設定できます。共通配置に戻すこともできます。
- **Notionタスク**：データベースを選ぶかURL・IDで指定し、列を対応付けてタスクを表示できます。追加、完了と取り消し、期限・状態・担当者による絞り込み、タスク本文の表示と編集に対応しました。既存の「Notionビュー」パネルも利用できます。
- **メモとテキスト**：パネル上で直接編集し、太字・下線・箇条書き・番号付きリストを自動保存します。メモとNotionタスクの文字サイズを5段階から選べます。
- **パネル操作**：クリックしたパネルの設定を中央に表示し、四辺と四隅からサイズを調整できます。ページの追加・並べ替え・削除と、WebパネルごとのURL・表示モードの編集にも対応しました。
- **ブラウザとメモリ**：WebリンクをMacの標準ブラウザで開きます。使われていないWebページや一時画像を解放し、メモリ使用量を抑えました。
- **更新機能**：GitHub Releasesから新しい版を確認し、通知または自動インストールを選べます。

### インストール

1. **Scrim-1.1.0.zip** をダウンロードして展開します。
2. Scrimを終了し、**Scrim.app** を「アプリケーション」フォルダにコピーして起動します。
3. ⌘キーの2回押しを使う場合は、macOSの「プライバシーとセキュリティ → 入力監視」でScrimを許可します。署名の異なる開発版から更新する場合は、許可の再設定が必要になることがあります。
4. Notionタスクを使う場合は、設定 → パネル →「Notion」でトークンを登録し、データベースと列を選んでください。トークンはMacのキーチェーンに保存されます。

### 対応環境と確認事項

- Apple Silicon（arm64）、macOS 14以降。Intel版は含まれません。
- バージョン **1.1.0（build 11）**。Developer ID署名、Apple公証、チケット添付済みの通常ビルドです。
- XCTestの202件がすべて成功し、ZIP展開後の署名・公証チケット・Gatekeeper検証に成功しました。
- Notionとの読み書きはローカルの模擬APIで確認しました。実際のNotionワークスペースと、実トラックパッドでの複数画面操作は未確認です。
- アプリの主な表示言語は日本語です。

## English

This update improves everyday use with per-display layouts, native Notion tasks, and editable notes.

### What's new

- **Per-display layouts:** Share panel content across displays while setting each display's position, size, stacking order, and visibility independently. You can switch back to a shared layout.
- **Notion tasks:** Choose a database or enter its URL or ID, map its properties, and view tasks in a native panel. Add and complete tasks, undo completion, filter by due date, status, or assignee, and view or edit task content. The existing Notion view panel remains available.
- **Notes and text:** Edit directly in a panel with automatically saved bold, underline, bullets, and numbered lists. Choose from five text sizes for notes and Notion tasks.
- **Panel controls:** Open a panel's settings in the center, resize from its edges and corners, manage pages, and edit each web panel's URL and display mode.
- **Browser and memory:** Open web links in your Mac's default browser. Unused web pages and temporary images are released to reduce memory use.
- **Updates:** Check GitHub Releases for updates and opt into notifications or automatic installation.

### Install

1. Download and unzip **Scrim-1.1.0.zip**.
2. Quit Scrim, copy **Scrim.app** to Applications, and launch it.
3. For the Command double-tap gesture, grant Input Monitoring access under macOS Privacy & Security. You may need to grant it again when moving from a development build signed with a different certificate.
4. For Notion tasks, add a token under Settings → Panels → Notion, then select a database and map its properties. The token is stored in macOS Keychain.

### Requirements and validation

- Apple Silicon (arm64), macOS 14 or later. No Intel build is included.
- Version **1.1.0 (build 11)**, a regular Developer ID-signed, Apple-notarized and stapled build.
- All 202 XCTest tests passed. The extracted ZIP passed signature, stapling, and Gatekeeper checks.
- Notion reads and writes were checked against a local mock API. A live Notion workspace and multi-display gestures on a physical trackpad remain unverified.
- The app's primary UI language is Japanese.
