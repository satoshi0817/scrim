# Scrim 1.0.0

## 日本語

Scrim の最初の正式リリースです。Sheerpane のオーバーレイブラウザを引き継ぎ、予定・時計・天気などを作業中の画面に重ねて使えるアプリになりました。

### 主な機能

- **すぐに呼び出せるオーバーレイ**：⌘を2回押すと固定表示、2回目を押したままにすると一時表示。メニューバーからも開けます。一時表示中のクリック・スクロールは設定で切り替えられます。
- **ドラッグでレイアウト**：「パネルを追加」からクリックまたはドラッグして配置。周囲のパネルが置き場所に合わせて移動・縮小し、サイズ変更後はグリッドに揃います。ディスプレイ別の配置にも対応します。
- **予定と会議**：次の予定、月間カレンダー、出欠表示、カレンダー選択、表示日数・除外キーワードの設定、Meet／Zoomへの参加リンク。再表示時に現在の時間帯へ移動できます。対応するMacではノッチ横にも承諾済み予定のカウントダウンを表示します。
- **時計・天気・電卓**：アナログ／デジタル時計、複数都市の時刻と勤務時間の比較、東京の天気と3時間ごとの予報、キーボードで操作できる電卓。
- **Webとローカルコンテンツ**：WebページやNotionビュー、PDF・テキスト・ローカルHTMLを表示。テキスト／HTMLの作成と編集、関連画像やCSSを含むHTMLフォルダの取り込みにも対応します。
- **使い方に合わせた設定**：ライト／ダーク／システムの外観、ログイン時の起動、Dock表示、画面キャプチャからの除外設定。

### インストールと初回設定

1. このリリースの **Scrim-1.0.0.zip** をダウンロードして展開します。
2. 旧版を終了してから **Scrim.app** を「アプリケーション」フォルダにコピーし、起動します。
3. ⌘の2回押しを使う場合は、macOSの「プライバシーとセキュリティ → 入力監視」でScrimを許可します。⌃⌥Pのショートカットは入力監視なしでも利用できます。
4. 予定を表示する場合はカレンダーへのアクセスを許可し、表示するカレンダーを選びます。Google OAuthの設定は不要です。予定の追加・変更・削除は行いません。
5. メニューバーの「レイアウトを編集…」からパネルを追加します。固定表示中の⌘,で操作一覧、⌘⇧Eで編集切り替えができます。

### 旧版からの移行

- アプリ名は **Scrim**、bundle IDは `com.satoshi0817.Scrim` です。
- 初回起動時にSheerpane、次にChiraの設定を一度だけコピーします。既存のScrim設定が優先され、旧版の設定は変更しません。
- 旧アプリのWebログイン状態と入力監視の許可は移行しません。Webサービスへの再ログインや権限の再設定が必要になる場合があります。Apple Development署名の開発版から切り替える場合も、入力監視を再設定してください。

### 対応環境・配布と検証

- **Apple Silicon（arm64）、macOS 14以降**。このZIPにIntel版は含まれません。
- バージョン **1.0.0（build 9）**。診断なしの通常ビルドです。
- Developer ID署名、Apple公証、staple済み。ZIP展開後の署名・公証チケット・Gatekeeper検証を実施しています。
- 自動テスト182件が成功。Swiftコンパイラの型推論でビルドが停止する検証用天気データの式を分割しました。

### 制限事項

- アプリ内の主な表示言語は日本語です。このリリースノートとREADMEは日本語・英語を用意しています。
- 天気の対象は東京です。天気取得とWebコンテンツにはネットワーク接続が必要です。
- 画面共有・スクリーンショットからの除外はキャプチャ方式に依存し、すべてのアプリでの非表示を保証しません。macOS 15.7.9での追加操作検証では、除外をオフに戻した後のウィンドウ共有状態チェックが失敗しました。この切り替えは未解決の検証項目です。表示時フェードの中間不透明度チェックも失敗しており、アニメーションの実機確認が残っています。
- 実際の入力監視、個人カレンダー、会議参加、複数ディスプレイでの動作は利用環境によって異なります。自動テストはすべての実機操作の確認を代替しません。

## English

This is the first stable release of Scrim. Building on Sheerpane's overlay browser, Scrim brings calendars, clocks, weather, and web content onto the screen where you work.

### Highlights

- **Quick-access overlay:** Double-tap Command to pin it, or hold the second press for a temporary peek. You can also open it from the menu bar and configure clicking and scrolling during a peek.
- **Drag-to-place layouts:** Click or drag a card from Add Panel onto the canvas. Nearby panels move or shrink to make room; resized panels snap to the grid. Per-display layouts are supported.
- **Events and meetings:** Upcoming events, a monthly calendar, attendance status, calendar selection, configurable day ranges and exclusion keywords, and Meet/Zoom join links. Reopening can scroll to the current time. Supported Macs can display a countdown for accepted events beside the notch.
- **Clocks, weather, and calculator:** Analog/digital clocks, multiple cities and overlapping working hours, Tokyo weather with three-hour forecasts, and keyboard-driven arithmetic.
- **Web and local content:** Websites, Notion views, PDFs, text, and local HTML. Create and edit text/HTML panels, or import HTML folders with related images and stylesheets.
- **Preferences:** System/light/dark appearance, launch at login, Dock visibility, and an option to exclude windows from supported screen-capture methods.

### Installation and first launch

1. Download **Scrim-1.0.0.zip** from this release and unzip it.
2. Quit the previous version, copy **Scrim.app** into **Applications**, and launch it.
3. To use the Command double-tap gesture, allow Scrim under macOS **Privacy & Security → Input Monitoring**. The Control-Option-P shortcut remains available without Input Monitoring permission.
4. To display events, grant Calendar access and select your calendars. No Google OAuth configuration is required. Scrim does not create, edit, or delete calendar events.
5. Choose **レイアウトを編集…** (Edit Layout) from the menu bar to add panels. While pinned, Command-comma opens the action list and Command-Shift-E toggles layout editing.

### Upgrading

- The application is now **Scrim**, with bundle ID `com.satoshi0817.Scrim`.
- On first launch, settings are copied once from Sheerpane, then Chira. Existing Scrim settings take priority; the original settings are left unchanged.
- Web login sessions and Input Monitoring permissions are not migrated from the old apps. You may need to sign in again and grant permissions. When replacing an Apple Development-signed development build, reconfigure Input Monitoring as needed.

### Requirements, distribution, and validation

- **Apple Silicon (arm64), macOS 14 or later.** This ZIP does not include an Intel build.
- Version **1.0.0 (build 9)**, built without trial diagnostics.
- Developer ID-signed, notarized by Apple, and stapled. Signature, notarization ticket, and Gatekeeper checks are performed on the extracted ZIP.
- All 182 automated tests passed. A weather-fixture expression was split into smaller expressions to resolve a Swift compiler type-checking failure.

### Limitations

- The app's primary UI language is Japanese. These release notes and the README are available in Japanese and English.
- Weather currently covers Tokyo. Weather updates and web content require a network connection.
- Capture exclusion depends on the capture method and cannot guarantee that windows stay hidden in every screen-sharing or screenshot app. An additional interaction check on macOS 15.7.9 failed when checking window-sharing state after disabling exclusion. Validation of this toggle remains unresolved. The show-animation check also failed to observe intermediate opacity; real-world fade behavior remains unverified.
- Input Monitoring, personal calendars, meeting links, and multi-display behavior depend on your environment. Automated checks do not replace validation of every real-world interaction.
